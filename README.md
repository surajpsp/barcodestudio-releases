# Barcode Studio downloads

Desktop downloads for [Barcode Studio](https://barcodestudio.silentdev.online/).

Get Windows and macOS builds from [Releases](https://github.com/surajpsp/barcodestudio-releases/releases). Each release includes architecture-specific packages, SHA-256 checksums, and signing/testing notes.

The application source and build workflow are maintained in a separate private repository. This repository hosts public installers only.
